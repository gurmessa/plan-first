# Changelog

All notable changes to this project are documented here. Format loosely follows
[Keep a Changelog](https://keepachangelog.com/); this project uses [SemVer](https://semver.org/).

## [0.1.0] - 2026-11-01

### Added

- `SKILL.md` — agent-agnostic skill that turns an idea into a plan document set.
- Templates: PRD, Architecture, Workflow, Tech Stack, Implementation Plan, Status,
  Verification, and ADR.
- Mermaid diagram set: planning pipeline, document dependencies, component, primary
  sequence, session state, and milestone graph.
- Worked example: the FlightFinder agent's full document set, sanitised.
- `docs/compatibility.md` — structural validation and runtime report table.
- `README.md` — clone-and-symlink install instructions for any agent.
