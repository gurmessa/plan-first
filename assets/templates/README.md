# Templates

Each template answers one planning question. Copy the ones you need into your project's
`docs/` folder and fill them in.

| Template | Produces | Answers |
|----------|----------|---------|
| `PRD.template.md` | `docs/PRD.md` | What exactly does v1 do, and not do? |
| `ARCHITECTURE.template.md` | `docs/ARCHITECTURE.md` | How is it structured, and why? |
| `WORKFLOW.template.md` | `docs/WORKFLOW.md` | How does it behave at runtime? |
| `TECH_STACK.template.md` | `docs/TECH_STACK.md` | What are we building with, and why? |
| `IMPLEMENTATION_PLAN.template.md` | `docs/IMPLEMENTATION_PLAN.md` | In what order, and when is it done? |
| `STATUS.template.md` | `docs/STATUS.md` | Where are we right now? |
| `VERIFICATION.template.md` | `docs/VERIFICATION.md` | How do we prove it works? |
| `ADR.template.md` | `docs/adr/NNNN-title.md` | Why did we make this decision? |

Every template ends with an **exit checklist**. Do not consider a document finished until
its checklist passes.
